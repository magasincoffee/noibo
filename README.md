# MAGASIN NOIBO

Internal operations WebApp for MAGASIN.

## Structure
- `PROJECT_CONTROL/` — manifest, project map, dependency map and changelog
- `backend/` — Google Apps Script modules
- `frontend/` — Apps Script HTML frontend
- `docs/` — architecture, database and workflow documentation

## Runtime
Google Apps Script + Google Sheets + Google Workspace ecosystem.

## Source of truth
Canonical source files live under `backend/` and `frontend/`. Version-suffixed exports are treated as historical/reference copies unless explicitly promoted.
